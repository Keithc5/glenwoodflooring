# Glenwood Flooring Astro site

Standalone Astro website for Glenwood Flooring, created from the reusable business website template.

## Commands

```sh
npm install
npm run dev
npm run lint
npm run check
npm run build
```

Business content is configured in `src/config/sites/glenwood.ts`. Main navigation is defined once in `src/config/navigation.ts`.

The contact form is intentionally disabled until a confirmed form backend is selected. No deployment or remote Git repository is configured.
